MyTime Class

This program implements a MyTime class for working with time. It stores hours, minutes, and seconds using private fields.
The class includes the following methods:
ToString() – displays time in the format HH:MM.
ToSecSinceMidnight() – converts time into seconds since midnight.
FromSecSinceMidnight() – converts seconds back into hours, minutes, and seconds.
Normalize() – corrects time values if they exceed the normal range.
AddSeconds(), AddOneSecond(), AddOneMinute(), AddOneHour() – add time.
Difference() – calculates the difference between two time values in seconds.
WhatLesson() – determines the current lesson or break based on the time.

The Program class demonstrates how to create time objects and use the implemented methods.
